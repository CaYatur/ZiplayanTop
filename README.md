# Zıplayan Top (2022)

2022 · Dönen altıgen üzerinde renk eşleştirmeli zıplayan top oyunu (Unity, Android). Kaynak, APK'dan geri kazanıldı.

Top, dönen bir altıgenin üzerinde zıplıyor. Ekranın sağına ya da soluna dokunup altıgeni çevirerek topu kendi rengindeki kenara düşürmeniz gerekiyor. En yüksek skor kaydediliyor. Kod: `Ball.cs`, `Hexagon.cs`, `GameManager.cs`, `menumanager.cs`.

> **Kurtarılan kaynak:** Bu projenin orijinal kaynak kodu zamanla kayboldu. 2026'da elimde kalan Android APK dosyasından (30 Ocak 2022) AssetRipper ile geri kazanıldı. Kodun mantığı birebir aynıdır; yorum satırları ve bazı yerel değişken adları geri gelmez. İlk commit'in tarihi, orijinal derlemenin tarihidir.
>
> *Recovered source: the original project was lost; this code was recovered in 2026 from the compiled Android APK dosyasından (30 Ocak 2022) with AssetRipper. The first commit carries the original build date.*

**Unity sürümü:** 2021.2.8f1

Depodan çıkarılan üçüncü taraf içerik (lisans gereği): TextMeshPro örnek betikleri ve dokuları, Unity paket DLL'leri. Projeyi açtıktan sonra bu paketleri Unity Package Manager / Asset Store üzerinden ekleyebilirsiniz; Unity paketleri `Packages/manifest.json` ile otomatik yüklenir.

> **Arşiv notu:** Bu depo 2026'da orijinal dosyalarımdan arşivlendi. Commit tarihleri, dosyaların bilgisayarımdaki gerçek son değiştirilme tarihleridir. Derlenmiş dosyalar (.exe, .apk) depoya konmadı.
> **Archive note:** Archived in 2026 from my original files. Commit dates are the real last-modified dates of the files. Build outputs (.exe, .apk) are not included.
